In this section, we take a further step and work with **implicit feedback**. Unlike explicit feedback, which directly reflects a user's stated opinion, such as a rating from 1 to 5, implicit feedback is inferred from user behavior. Clicking a product, watching a video, listening to a song, adding a product to a shopping cart, and even the time spent on a page are all examples of implicit feedback.

This type of data is far more abundant than explicit feedback, which makes learning how to use it especially important in recommender systems. Implicit feedback is commonly recorded as binary values, $0$ or $1$, or as frequency values, such as the number of clicks. Unlike explicit feedback, it does not provide a direct rating scale.

The key difference from explicit feedback is the prediction objective. With explicit feedback, the goal is to predict the rating that a user would assign to an item. With implicit feedback, the goal is usually to estimate the likelihood that a user will interact with an item or, equivalently, to rank items for recommendation. We seek items with which the user has not yet interacted but is likely to find relevant or appealing.

## UBCF with Implicit Feedback

The overall process resembles the procedure for explicit feedback, but subtle differences arise in how the data are interpreted and how predictions are computed.

### 1. Representing the Data

We first construct a user-item interaction matrix. In the simplest case, we enter $1$ if a user has interacted with an item and $0$ otherwise. Interaction frequency or duration can also be used as a weight, but for simplicity, we begin with binary feedback.

Suppose there are $m$ users and $n$ items. The interaction matrix $R$ has dimensions $m\times n$. Its entry is $R_{ui}=1$ if user $u$ has interacted with item $i$, and $R_{ui}=0$ otherwise.

### 2. Computing User Similarity

For binary implicit feedback, similarity measures such as the **Jaccard index** and **cosine similarity** applied to binary vectors are particularly suitable. The Jaccard index between two users $u$ and $v$ is defined as:

$$Jaccard(u,v)=\frac{\lvert I_{u}\cap I_{v}\rvert}{\lvert I_{u}\cup I_{v}\rvert}$$

Here, $I_{u}$ is the set of items with which user $u$ has interacted, and $I_{v}$ is the corresponding set for user $v$. The index is the ratio of the number of items with which both users interacted to the total number of items with which at least one of them interacted.

### 3. Selecting Neighbors

For the target user $u_{a}$, the user for whom we want to generate recommendations, we select the $k$ most similar users according to the highest similarity values. This set is denoted by $N(u_{a})$.

### 4. Generating Recommendations by Scoring Items

This step is the principal difference from explicit-feedback UBCF. Rather than predicting a rating, we assign a **recommendation score** to each item with which target user $u_{a}$ has not yet interacted.

A common scoring method for an item $i$ that $u_{a}$ has not interacted with is the weighted sum of the neighbors' interactions with that item:

$$P(u_{a},i)=\sum_{u_{k}\in N(u_{a})}sim(u_{a},u_{k})\cdot R_{u_{k},i}$$

where:

- $P(u_{a},i)$ is the recommendation score of item $i$ for user $u_{a}$.
- $sim(u_{a},u_{k})$ is the similarity between target user $u_{a}$ and neighbor $u_{k}$.
- $R_{u_{k},i}$ equals $1$ if neighbor $u_{k}$ has interacted with item $i$, and $0$ otherwise.

This formula means that an item receives a higher score when similar users have interacted with it. Greater similarity and stronger interaction signals increase the recommendation score.

After calculating a recommendation score for every item with which the target user has not interacted, we sort the items in descending order of score and present the top-$N$ items as recommendations.

## Example

Suppose we have the following user interactions with several products, where $1$ indicates a purchase or click and $0$ indicates no interaction:

| User | Product 1 | Product 2 | Product 3 | Product 4 | Product 5 |
|---|---:|---:|---:|---:|---:|
| User A | 1 | 1 | 0 | 0 | 0 |
| User B | 1 | 1 | 1 | 0 | 0 |
| User C | 0 | 1 | 1 | 1 | 0 |
| User D | 1 | 0 | 0 | 1 | 1 |
| User E | 0 | 0 | 1 | 0 | 1 |

We want to generate recommendations for User A. Let $k=2$ be the desired number of neighbors, and use the Jaccard index to calculate similarity.

### Step 1: Representing the Data

The data are already presented in matrix form.

The following example requires Python with the `pandas` and `numpy` packages installed. It assumes that each product-interaction value is binary, with $1$ representing an observed interaction and $0$ representing no observed interaction.

```python
import pandas as pd
import numpy as np

# مرحله ۱: نمایش داده‌ها
data = {
    'کاربر': ['A', 'B', 'C', 'D', 'E'],
    'کالای۱': [1, 1, 0, 1, 0],
    'کالای۲': [1, 1, 1, 0, 0],
    'کالای۳': [0, 1, 1, 0, 1],
    'کالای۴': [0, 0, 1, 1, 0],
    'کالای۵': [0, 0, 0, 1, 1]
}
df = pd.DataFrame(data)
df = df.set_index('کاربر')

print("ماتریس تعاملات کاربر-آیتم:")
print(df)
print("-" * 30)

# کاربر هدف
target_user = 'A'
# تعداد همسایگان
k = 2
# آیتم‌های کاربر هدف
target_user_items = set(df.loc[target_user][df.loc[target_user] == 1].index)
print(f"آیتم‌های کاربر هدف ({target_user}): {target_user_items}")
```

### Step 2: Calculating Similarity Between User A and the Other Users

The set of items for User A is $I_{A}=\{\text{Product 1},\text{Product 2}\}$.

The corresponding sets for the other users are:

$$I_{B}=\{\text{Product 1},\text{Product 2},\text{Product 3}\}$$

$$I_{C}=\{\text{Product 2},\text{Product 3},\text{Product 4}\}$$

$$I_{D}=\{\text{Product 1},\text{Product 4},\text{Product 5}\}$$

$$I_{E}=\{\text{Product 3},\text{Product 5}\}$$

For User A and User B:

$$\lvert I_{A}\cap I_{B}\rvert=2,\quad I_{A}\cap I_{B}=\{\text{Product 1},\text{Product 2}\}$$

$$\lvert I_{A}\cup I_{B}\rvert=3,\quad I_{A}\cup I_{B}=\{\text{Product 1},\text{Product 2},\text{Product 3}\}$$

$$J(A,B)=\frac{2}{3}\approx0.667$$

For User A and User C:

$$\lvert I_{A}\cap I_{C}\rvert=1,\quad I_{A}\cap I_{C}=\{\text{Product 2}\}$$

$$\lvert I_{A}\cup I_{C}\rvert=4,\quad I_{A}\cup I_{C}=\{\text{Product 1},\text{Product 2},\text{Product 3},\text{Product 4}\}$$

$$J(A,C)=\frac{1}{4}=0.25$$

For User A and User D:

$$\lvert I_{A}\cap I_{D}\rvert=1,\quad I_{A}\cap I_{D}=\{\text{Product 1}\}$$

$$\lvert I_{A}\cup I_{D}\rvert=4,\quad I_{A}\cup I_{D}=\{\text{Product 1},\text{Product 2},\text{Product 4},\text{Product 5}\}$$

$$J(A,D)=\frac{1}{4}=0.25$$

For User A and User E:

$$\lvert I_{A}\cap I_{E}\rvert=0,\quad I_{A}\cap I_{E}=\varnothing$$

$$\lvert I_{A}\cup I_{E}\rvert=4,\quad I_{A}\cup I_{E}=\{\text{Product 1},\text{Product 2},\text{Product 3},\text{Product 5}\}$$

$$J(A,E)=\frac{0}{4}=0.0$$

```python
# مرحله ۲: محاسبه شباهت کاربران (با استفاده از ضریب ژاکارد)
user_similarities = {}

# آیتم‌های کاربر هدف به صورت مجموعه
set_target_user = set(df.columns[df.loc[target_user] == 1])

for other_user in df.index:
    if other_user == target_user:
        continue # خود کاربر با خودش مقایسه نمی‌شود

    set_other_user = set(df.columns[df.loc[other_user] == 1])

    intersection = len(set_target_user.intersection(set_other_user))
    union = len(set_target_user.union(set_other_user))

    if union == 0: # برای جلوگیری از تقسیم بر صفر اگر هر دو کاربر هیچ آیتمی نداشته باشند
        jaccard_similarity = 0
    else:
        jaccard_similarity = intersection / union

    user_similarities[other_user] = jaccard_similarity

print("شباهت سایر کاربران با کاربر هدف:")
# مرتب‌سازی شباهت‌ها برای نمایش بهتر
sorted_similarities = dict(sorted(user_similarities.items(), key=lambda item: item[1], reverse=True))
for user, sim in sorted_similarities.items():
    print(f"شباهت با کاربر {user}: {sim:.3f}")
print("-" * 30)
```

### Step 3: Selecting Neighbors

Sorting users by their similarity to User A gives:

1. User B: $0.667$
2. User C: $0.25$
3. User D: $0.25$
4. User E: $0.0$

With $k=2$, the two nearest neighbors are User B and User C. When similarities are tied, as they are for Users C and D, an implementation may choose either user according to a defined tie-breaking rule. In this example, User C is selected.

```python
# مرحله ۳: انتخاب همسایگان
# همسایگان بر اساس بالاترین شباهت انتخاب می‌شوند
neighbors = sorted(user_similarities.items(), key=lambda item: item[1], reverse=True)[:k]
neighbor_names = [n[0] for n in neighbors]
neighbor_similarities = {n[0]: n[1] for n in neighbors}

print(f"{k} همسایه برتر کاربر {target_user}: {neighbor_names}")
print("شباهت همسایگان:", neighbor_similarities)
print("-" * 30)
```

### Step 4: Generating Recommendations by Scoring Items

User A has interacted with Product 1 and Product 2. We therefore score Product 3, Product 4, and Product 5.

For Product 3:

$$P(A,\text{Product 3})=sim(A,B)\cdot R_{B,\text{Product 3}}+sim(A,C)\cdot R_{C,\text{Product 3}}$$

$$P(A,\text{Product 3})=(0.667\cdot1)+(0.25\cdot1)$$

$$P(A,\text{Product 3})=0.667+0.25=0.917$$

Both User B and User C interacted with Product 3.

For Product 4:

$$P(A,\text{Product 4})=sim(A,B)\cdot R_{B,\text{Product 4}}+sim(A,C)\cdot R_{C,\text{Product 4}}$$

$$P(A,\text{Product 4})=(0.667\cdot0)+(0.25\cdot1)$$

$$P(A,\text{Product 4})=0+0.25=0.25$$

User B did not interact with Product 4, whereas User C did.

For Product 5:

$$P(A,\text{Product 5})=sim(A,B)\cdot R_{B,\text{Product 5}}+sim(A,C)\cdot R_{C,\text{Product 5}}$$

$$P(A,\text{Product 5})=(0.667\cdot0)+(0.25\cdot0)$$

$$P(A,\text{Product 5})=0+0=0.0$$

Neither User B nor User C interacted with Product 5.

```python
# مرحله ۴: تولید پیشنهاد (امتیازدهی به آیتم‌ها)
item_scores = {}
all_items = df.columns

# آیتم‌هایی که کاربر هدف با آن‌ها تعامل نداشته است
items_to_recommend = [item for item in all_items if item not in target_user_items]
print(f"آیتم‌های کاندید برای پیشنهاد به کاربر {target_user}: {items_to_recommend}")

for item in items_to_recommend:
    score = 0
    for neighbor_name in neighbor_names:
        # آیا همسایه با این آیتم تعامل داشته؟
        interaction = df.loc[neighbor_name, item]
        # شباهت همسایه
        similarity = neighbor_similarities[neighbor_name]
        score += similarity * interaction
    item_scores[item] = score

print("\nامتیاز پیشنهاد برای هر آیتم کاندید:")
for item, score in item_scores.items():
    print(f"آیتم {item}: {score:.3f}")
print("-" * 30)

# مرحله ۵: ارائه پیشنهاد نهایی
sorted_recommendations = sorted(item_scores.items(), key=lambda item: item[1], reverse=True)

print(f"پیشنهادات نهایی برای کاربر {target_user} (مرتب شده):")
for item, score in sorted_recommendations:
    print(f"- {item} (امتیاز: {score:.3f})")

if sorted_recommendations:
    print(f"\nبهترین پیشنهاد برای کاربر {target_user}: {sorted_recommendations[0][0]}")
else:
    print(f"\nهیچ پیشنهادی برای کاربر {target_user} یافت نشد.")
```

### Step 5: Presenting the Final Recommendations

The recommendation scores for the items that User A has not yet encountered are:

| Item | Recommendation score |
|---|---:|
| Product 3 | 0.917 |
| Product 4 | 0.25 |
| Product 5 | 0.0 |

In descending order, the ranking is:

1. Product 3: $0.917$
2. Product 4: $0.25$
3. Product 5: $0.0$

Therefore, if one recommendation is required for User A, Product 3 is the best choice. If two recommendations are required, Product 3 should be followed by Product 4. User B, who is highly similar to User A, interacted with Product 3 and therefore made the greatest contribution to its high recommendation score.

## Interpreting the Result

At first glance, the output of this implicit-feedback lesson may appear similar to the output of the preceding lesson on explicit data. In both cases, user-based collaborative filtering uses the preferences or behavior of similar users to recommend one or more items to the target user.

The interpretation, however, differs. With explicit feedback, similarity measures and prediction formulas estimate the rating, such as a rating out of five stars, that a user would likely assign to an item; items with the highest predicted ratings are then recommended. With implicit feedback, the procedure ranks items according to behavioral evidence from similar users. In this simple example, only Product 3 might be recommended in a real system, while lower-scoring items could be omitted according to the chosen recommendation cutoff.

## Summary

UBCF with implicit feedback converts observed behavior into ranked recommendations. The essential stages are representing interactions, calculating user similarity, selecting the nearest neighbors, and assigning recommendation scores to unseen items from neighbors' weighted interaction signals. Because implicit interactions do not directly express preference or dislike, their meaning depends on the domain and event type. A click, purchase, listening event, and long dwell time should therefore not automatically be treated as equally strong evidence of interest.
