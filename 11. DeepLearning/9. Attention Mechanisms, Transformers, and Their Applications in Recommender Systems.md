One of the most influential developments in artificial intelligence and deep learning has been the introduction of **Attention Mechanisms**, followed by the development of the **Transformer** architecture. These innovations have substantially improved the performance of deep learning models across numerous applications while addressing several limitations of earlier neural architectures.

This section first examines the fundamental principles of attention and Transformers. It then explores their applications in recommender systems through **Attentive Collaborative Filtering (ACF)** and **BERT4Rec**.

## 9.1. Attention Mechanisms

Different neural network architectures process information in different ways. However, not every component of an input contributes equally to a prediction.

Consider reading a lengthy document to answer a specific question. Rather than treating every word and sentence as equally important, a reader concentrates on the passages most relevant to the question.

The **Attention Mechanism** introduces a similar capability into deep learning models.

Attention enables a model to dynamically identify and emphasize the most relevant components of its input according to the current prediction context.

Unlike fixed aggregation methods, such as averaging or summing all input representations with equal importance, attention assigns different weights to different pieces of information.

### 9.1.1. Query, Key, and Value Representations

The attention mechanism is commonly formulated using three types of vectors:

- **Query (Q):** Represents the information the model is currently seeking.
- **Key (K):** Represents the characteristics used to determine the relevance of each available information source.
- **Value (V):** Represents the information that will be aggregated to construct the output.

In a recommender system, these representations may correspond to:

- A query describing the user's current preferences.
- Keys representing previously interacted items or behavioral patterns.
- Values containing the feature representations associated with those items.

The attention mechanism determines which keys are most relevant to the query and uses their corresponding values to construct a context-dependent representation.

This process consists of three principal stages:

1. Computing similarity scores.
2. Converting similarity scores into attention weights.
3. Aggregating value vectors using the resulting weights.

### 9.1.2. Computing Similarity Scores

Let $\mathbf{q}$ denote a query vector and $\mathbf{k}_{i}$ the key vector associated with the $i$-th information source.

A simple attention scoring function uses the dot product:

$$
e_{i}=\mathbf{q}^{\top}\mathbf{k}_{i}
$$

Where:

- $\mathbf{q}$ is the query vector.
- $\mathbf{k}_{i}$ is the $i$-th key vector.
- $e_{i}$ is the compatibility score between the query and the key.

A larger dot product generally indicates stronger compatibility between the query and key in the learned representation space.

For example, if the query represents a user's current interest in science-fiction movies, keys associated with relevant science-fiction content may receive higher scores.

The scoring function determines which pieces of information are most relevant to the current context.

### 9.1.3. Converting Similarity Scores into Attention Weights

The similarity scores are converted into normalized attention weights using the **Softmax Function**:

$$
\alpha_{i}=\frac{\exp(e_{i})}{\sum_{j}\exp(e_{j})}
$$

Where:

- $\alpha_{i}$ is the attention weight assigned to the $i$-th key.
- $\exp(e_{i})$ is the exponential transformation of the similarity score.
- The denominator normalizes the scores across all available keys.

The resulting weights satisfy:

$$
0\le\alpha_{i}\le1
$$

$$
\sum_{i}\alpha_{i}=1
$$

These properties allow the attention weights to be interpreted as relative importance coefficients.

For example, an attention weight of $0.9$ indicates that a particular information source contributes substantially more to the resulting representation than another source with a weight of $0.01$.

The exponential transformation also amplifies differences between compatibility scores.

### 9.1.4. Weighted Aggregation of Value Vectors

After calculating the attention weights, the model combines the corresponding value vectors.

The attention output is:

$$
Attention(\mathbf{q},\{(\mathbf{k}_{i},\mathbf{v}_{i})\})=\sum_{i}\alpha_{i}\mathbf{v}_{i}
$$

Where:

- $\mathbf{v}_{i}$ is the value vector associated with key $\mathbf{k}_{i}$.
- $\alpha_{i}$ is the corresponding attention weight.
- The weighted sum produces the attention output.

The result is a **Contextualized Representation**, meaning that the aggregated information depends on the current query.

A value vector may be identical to its corresponding key vector, but the two representations can also be different.

The essential property is that the query determines how strongly each value contributes to the output.

### 9.1.5. Advantages of Attention-Based Aggregation

Attention provides several advantages over fixed aggregation methods.

**Dynamic Relevance Weighting**

The importance of each input component changes according to the current query.

**Selective Information Aggregation**

The model can emphasize information that is most useful for the current prediction while reducing the influence of less relevant components.

**Richer Representations**

Attention can produce representations that reflect relationships among input components rather than treating all information uniformly.

**Potential Interpretability**

Attention weights can indicate which input components received greater emphasis during prediction.

For example, consider a movie recommendation system in which a user has demonstrated an interest in science-fiction movies featuring Tom Hanks.

An attention-based model may assign greater weights to relevant genre and actor features when constructing the user's preference representation.

These weights can provide useful information about the model's internal processing, although they should not automatically be interpreted as complete causal explanations of its recommendations.

## 9.2. Transformers

Earlier neural architectures addressed sequential information through different mechanisms.

**Recurrent Neural Networks (RNNs)** maintain hidden states that summarize previous observations.

**Convolutional Neural Networks (CNNs)** identify local patterns and combine them into increasingly complex representations.

However, both architectures have limitations when modeling relationships across long sequences.

RNNs require sequential computation, while conventional CNNs rely on local receptive fields that expand through successive layers.

The Transformer architecture introduced a different approach based primarily on attention.

The central idea, presented in the paper *Attention Is All You Need*, is that sequence relationships can be modeled effectively without relying on recurrence or convolution as the principal sequence-processing mechanism.

### 9.2.1. Self-Attention

The fundamental operation in a Transformer is **Self-Attention**.

In self-attention, each element of a sequence can attend to other elements within the same sequence.

Consider a sequence of items previously purchased by a user.

For each item, self-attention evaluates its relationship with the other items and constructs a new representation that incorporates relevant contextual information.

For example, an item representing a computer keyboard may attend strongly to previous interactions involving a mouse, monitor, or other computer accessories.

The resulting representation contains information about both the item itself and its relationships with other items in the sequence.

This differs from a conventional recurrent architecture, where information is propagated through successive hidden states.

Self-attention allows direct interactions between sequence positions, subject to any attention masks imposed by the model.

### 9.2.2. Scaled Dot-Product Attention

Transformers commonly use **Scaled Dot-Product Attention**.

Given matrices of queries, keys, and values, attention is computed as:

$$
Attention(\mathbf{Q},\mathbf{K},\mathbf{V})=softmax\left(\frac{\mathbf{Q}\mathbf{K}^{\top}}{\sqrt{d_{k}}}\right)\mathbf{V}
$$

Where:

- $\mathbf{Q}$ contains the query vectors.
- $\mathbf{K}$ contains the key vectors.
- $\mathbf{V}$ contains the value vectors.
- $d_{k}$ is the dimensionality of the key vectors.
- $\mathbf{Q}\mathbf{K}^{\top}$ contains pairwise query–key compatibility scores.
- $softmax$ normalizes the scores into attention weights.

The scaling factor:

$$
\frac{1}{\sqrt{d_{k}}}
$$

reduces the magnitude of dot products when the key dimensionality is large.

Without this scaling, large dot-product values may cause the softmax function to become highly concentrated, potentially producing very small gradients.

Scaled dot-product attention therefore supports more stable optimization.

### 9.2.3. Position-Wise Feed-Forward Networks

After self-attention, the resulting contextualized representations are processed by a **Position-Wise Feed-Forward Network (FFN)**.

This component is typically implemented as a small multilayer perceptron.

A common formulation is:

$$
FFN(\mathbf{x})=\mathbf{W}_{2}\phi(\mathbf{W}_{1}\mathbf{x}+\mathbf{b}_{1})+\mathbf{b}_{2}
$$

Where:

- $\mathbf{x}$ is the input representation.
- $\mathbf{W}_{1}$ and $\mathbf{W}_{2}$ are learnable weight matrices.
- $\mathbf{b}_{1}$ and $\mathbf{b}_{2}$ are bias vectors.
- $\phi$ is a nonlinear activation function.

The same feed-forward network is applied independently to each sequence position.

This introduces additional nonlinear modeling capacity after the attention operation.

A Transformer layer typically combines attention and feed-forward transformations with residual connections and normalization operations.

### 9.2.4. Multi-Head Attention

Transformers generally employ **Multi-Head Attention** rather than relying on a single attention operation.

Each attention head learns separate projections of the input representations.

These projections allow different heads to capture different relationships among sequence elements.

For example, in a recommendation sequence:

- One attention head may emphasize relationships between items from similar categories.
- Another may emphasize complementary products.
- Another may capture patterns associated with recent interactions.

The outputs of the attention heads are combined to construct the final representation.

Multi-head attention enables the model to examine relationships from multiple learned representation subspaces.

### 9.2.5. Positional Encoding

Unlike RNNs, Transformers do not inherently process input elements one at a time in sequential order.

Consequently, a Transformer requires an explicit mechanism for representing the positions of elements in a sequence.

This is commonly achieved through **Positional Encoding** or learned positional embeddings.

Positional information is incorporated into the input representations so that the model can distinguish between different sequence arrangements.

For example, the sequences:

- Mouse, Keyboard, Monitor
- Monitor, Keyboard, Mouse

contain the same items but in different orders.

In sequential recommendation, this ordering may provide important information about the user's evolving interests.

Positional representations allow the Transformer to incorporate such information into its predictions.

### 9.2.6. Advantages of Transformers

The Transformer architecture offers several important advantages.

**Parallel Processing**

Unlike conventional RNNs, Transformer training does not require hidden states to be computed sequentially across all positions.

This enables greater parallelization during training.

**Direct Modeling of Long-Range Relationships**

Self-attention allows distant sequence positions to interact directly.

**Flexible Contextual Representation Learning**

Each element can incorporate information from other relevant elements in the sequence.

**Multiple Attention Patterns**

Multi-head attention enables the model to learn different types of relationships simultaneously.

These properties have contributed to major advances in natural language processing, computer vision, and recommender systems.

Well-known Transformer-based architectures include BERT and GPT.

However, standard self-attention also has computational limitations. In particular, its attention matrix grows quadratically with sequence length, which can make processing extremely long sequences expensive.

## 9.3. Attentive Collaborative Filtering (ACF)

Attention mechanisms can also be incorporated into collaborative filtering.

Consider a multimedia recommendation platform that has access to several sources of information:

- User purchase histories.
- Images of previously viewed products.
- Textual product descriptions.
- Audio characteristics of music.
- Other item-related features.

These information sources do not necessarily contribute equally to understanding a user's preferences.

Some previously interacted items may be more representative of the user's interests than others.

Similarly, certain components of an item's multimedia representation may be more relevant than other components.

**Attentive Collaborative Filtering (ACF)** addresses these challenges by introducing a two-level attention mechanism into a latent-factor recommendation framework.

The two levels are:

1. **Item-Level Attention**
2. **Component-Level Attention**

### 9.3.1. Item-Level Attention

Item-level attention determines the relative importance of items in a user's interaction history.

Suppose a user has watched 100 movies.

Not all these movies necessarily reflect the user's preferences equally well.

Some may have been watched accidentally or only once, while others may represent strong and consistent interests.

For example, five frequently watched favorite movies may provide more useful information about the user's preferences than the remaining 95 movies.

Item-level attention learns to assign larger weights to more informative historical interactions.

As a result, the user's preference representation emphasizes the items that are most relevant to the recommendation task.

This allows the model to avoid treating all historical interactions as equally important.

### 9.3.2. Component-Level Attention

Component-level attention operates at a more detailed level.

Instead of assigning importance only to entire items, it determines the relative importance of individual components within their multimedia representations.

For example, a clothing product may contain visual features associated with:

- Color.
- Fabric texture.
- Shape.
- Pattern.
- Decorative details.

A particular user may care more about color and fabric than about button design.

Similarly, a music recommendation model may discover that rhythm and melody are more informative than lyrical content for a particular user's preferences.

Component-level attention allows the model to emphasize these relevant characteristics.

Consequently, the recommendation process becomes sensitive not only to which historical items matter but also to which features within those items are most informative.

### 9.3.3. Two-Level Attention Architecture

ACF combines item-level and component-level attention to learn richer user preference representations.

The two mechanisms perform complementary functions.

**Item-Level Attention**

Identifies the most informative items in the user's interaction history.

**Component-Level Attention**

Identifies the most informative multimedia components associated with those items.

Together, these mechanisms enable adaptive weighting across both historical interactions and item features.

This differs from fixed aggregation approaches that assign equal importance to all items or feature components.

### 9.3.4. End-to-End Training

The attention modules in ACF are implemented using neural networks.

They are trained jointly with the recommendation model through an end-to-end optimization procedure.

The original framework uses stochastic gradient-based optimization and a pairwise ranking objective.

The ranking objective encourages the model to assign higher scores to items associated with positive user preferences than to less-preferred or unobserved items.

During training, the model simultaneously learns:

- Which historical items should receive greater attention.
- Which multimedia components should receive greater attention.
- How these representations should influence personalized ranking.

This joint optimization allows the attention mechanisms to adapt to the recommendation objective.

### 9.3.5. Advantages of ACF

ACF offers several benefits for multimedia recommendation.

**Adaptive Weighting**

The model dynamically assigns importance to historical items and their multimedia components.

**Improved Preference Representation**

By emphasizing informative interactions and features, the model can construct richer user representations.

**Multimedia Integration**

The architecture can incorporate information from images, text, audio, and other item-related modalities.

**Potential Interpretability**

Attention weights can indicate which historical items and feature components contributed most strongly to a recommendation.

**Improved Recommendation Accuracy**

Experimental evaluations on multimedia recommendation datasets such as Vine and Pinterest have reported improvements over fixed aggregation and simpler hybrid recommendation approaches.

The two-level attention structure makes ACF a flexible framework for incorporating multimedia features into existing collaborative filtering pipelines.

## 9.4. BERT4Rec: Transformer-Based Sequential Recommendation

Sequential recommendation aims to predict items that a user is likely to interact with based on their previous behavior.

Traditional sequential models, including RNN-based approaches, often process interaction histories from beginning to end.

These models learn representations from preceding interactions and use them to predict subsequent items.

However, unidirectional processing does not fully exploit relationships among all elements of an observed sequence during representation learning.

**BERT4Rec** addresses this limitation by applying deep bidirectional Transformer encoders to sequential recommendation.

The model is based on the principle of **Bidirectional Encoder Representations from Transformers (BERT)**.

### 9.4.1. Representing User Interactions as Item Sequences

BERT4Rec treats a user's interaction history as a sequence of item tokens.

For example, a user's purchase history might be:

$$
S_{u}=(i_{1},i_{2},i_{3},i_{4},i_{5})
$$

Where:

- $S_{u}$ is the interaction sequence for user $u$.
- $i_{t}$ is the item associated with position $t$.

Each item is converted into an embedding representation.

Positional embeddings are also incorporated so that the model can distinguish the ordering of interactions.

The resulting sequence is processed by multiple Transformer encoder layers.

### 9.4.2. Bidirectional Self-Attention

BERT4Rec uses **Bidirectional Self-Attention**.

Unlike a strictly left-to-right model, bidirectional self-attention allows an item representation to incorporate information from both preceding and subsequent positions in the observed training sequence.

This provides a more complete contextual representation of the sequence.

For example, when reconstructing an item located in the middle of a purchase history, the model can use information from items appearing on both sides.

This is particularly valuable when the surrounding interactions jointly provide evidence about the missing item.

### 9.4.3. Masked Item Prediction

BERT4Rec is trained using a **Masked Item Prediction** objective.

During training, selected items in a user's interaction sequence are randomly masked.

The model must reconstruct the identities of the masked items using the remaining visible interactions.

This is analogous to masked language modeling in BERT.

Instead of predicting missing words, BERT4Rec predicts missing item tokens.

The training process encourages the model to learn contextual relationships among items.

### 9.4.4. Example of BERT4Rec Training

Suppose a user's purchase history is:

```text
[Headphones, Mouse, Speakers, Keyboard, Monitor]
```

During training, one item is randomly masked.

The resulting input becomes:

```text
[Headphones, Mouse, [MASK], Keyboard, Monitor]
```

The model's objective is to reconstruct the masked item:

```text
Speakers
```

Using bidirectional self-attention, the model can consider:

- **Left context:** Headphones and Mouse.
- **Right context:** Keyboard and Monitor.

The model learns relationships among these items and estimates which item is most likely to occupy the masked position.

The availability of both left and right context allows the model to learn richer representations of user behavior.

### 9.4.5. Transformer Encoder Architecture

BERT4Rec consists of multiple Transformer encoder layers.

Each layer contains:

- Multi-head self-attention.
- Position-wise feed-forward networks.
- Residual connections and normalization mechanisms.

The architecture also incorporates positional information to preserve the order of user interactions.

Through successive encoder layers, the model learns increasingly contextualized representations of the interaction sequence.

These representations capture relationships among items and support masked item reconstruction.

### 9.4.6. Next-Item Recommendation

Although BERT4Rec is trained through masked item prediction, it can also be used for next-item recommendation.

At inference time, a special mask token can be appended to the end of the observed interaction sequence.

For example:

```text
[Headphones, Mouse, Keyboard, Monitor, [MASK]]
```

The model predicts the item most likely to occupy the masked position.

Candidate items can then be ranked according to their predicted probabilities.

This approach enables BERT4Rec to apply representations learned through bidirectional masked training to next-item recommendation.

Importantly, future interactions are not available during real-world next-item prediction. The model therefore uses only the observed interaction history and the appended mask token at inference time.

### 9.4.7. Advantages of BERT4Rec

BERT4Rec offers several important advantages.

**Bidirectional Contextual Learning**

The model can use both preceding and subsequent observed items during masked item reconstruction.

**Rich Sequential Representations**

Multiple Transformer encoder layers learn complex relationships among items.

**Flexible Dependency Modeling**

Self-attention can directly connect distant positions within an interaction sequence.

**Effective Representation Learning**

The masked item prediction objective encourages the model to learn meaningful contextual patterns.

**Improved Recommendation Performance**

Experiments on public datasets, including Amazon Beauty, Steam, and MovieLens, have demonstrated improvements over several earlier sequential recommendation approaches, including RNN-based models.

These results illustrate the potential of Transformer-based architectures for modeling user behavior and improving sequential recommendation accuracy.

The applications of Transformers in recommender systems extend beyond BERT4Rec. Their flexibility has encouraged the development of numerous additional architectures that combine attention with collaborative filtering, content-based modeling, and other recommendation techniques.
