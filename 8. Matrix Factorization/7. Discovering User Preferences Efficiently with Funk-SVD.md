
In the previous sections, we examined the enormous size and inherent sparsity of user–item interaction matrices in real-world recommender systems. We also discussed why traditional collaborative filtering methods face significant challenges at this scale, particularly regarding scalability and the cold-start problem.

We introduced the fundamental idea of matrix factorization: approximating a large interaction matrix $R$ as the product of two smaller matrices, $P$ and $Q$, representing latent user preferences and latent item characteristics, respectively. By learning these matrices, we can discover hidden patterns in interaction data and predict previously unobserved ratings.

We now examine the first practical algorithm for learning these latent representations: Funk-SVD.

Introduced by Simon Funk during the Netflix Prize competition, Funk-SVD was one of the earliest influential applications of matrix factorization to recommender systems. Its underlying approach subsequently provided a foundation for numerous recommendation algorithms.

## Understanding User Preferences and Latent Item Characteristics

Consider why a particular user likes or dislikes a movie. Their preference might be influenced by the film's genre, actors, director, or overall atmosphere. These are observable characteristics that can often be identified directly from item metadata.

However, user preferences may also depend on deeper characteristics that are not explicitly recorded in the dataset.

Funk-SVD is based on the idea that both users and items can be represented through a set of latent features.

For users, these features form a preference profile. For example, they might represent the extent to which someone enjoys action movies, comedies, or artistic films.

For items, latent features describe underlying characteristics. For example, a movie might contain varying degrees of action, comedy, artistic expression, and other characteristics.

These representations consist of $k$ latent features.

Importantly, learned latent features do not necessarily correspond directly to recognizable concepts such as movie genres. Instead, they are numerical dimensions inferred from interaction data and may capture combinations of multiple underlying characteristics.

The matrix $P$, with dimensions $U \times k$, contains the latent preference profiles of users. Each row represents one user.

Similarly, the matrix $Q$, with dimensions $k \times I$, contains the latent characteristics of items. Each column represents one item.

To predict how much user $u$ will like item $i$, Funk-SVD measures the compatibility between their latent representations using the dot product:

$$[ \widehat{R}_{u,i} = P[u,:] \cdot Q[:,i] ]$$

### Matrix Indexing Convention

Throughout this section, square brackets indicate matrix indexing.

The expression `P[u,:]` refers to row $u$ and all columns of matrix $P$. In other words, it represents the complete latent feature vector of user $u$.

Similarly, `Q[:,i]` refers to all rows and column $i$ of matrix $Q$, representing the complete latent feature vector of item $i$.

The objective of Funk-SVD is to learn the matrices $P$ and $Q$ so that their dot products approximate actual observed ratings as closely as possible.

## Minimizing Prediction Error

To learn the matrices $P$ and $Q$, Funk-SVD requires a mathematical objective: minimizing a function that measures the model's prediction error.

This function is called the loss function, which was introduced in the earlier discussion of matrix factorization.

A commonly used regularized loss function is:

$$[ Loss = \sum_{(u,i) \in \Omega} \left(R[u,i] - P[u,:] \cdot Q[:,i]\right)^{2} + \lambda\left(\lVert P \rVert_{F}^{2} + \lVert Q \rVert_{F}^{2}\right) ]$$

Here:

- $R[u,i]$ is the actual rating assigned by user $u$ to item $i$.
    
- $P[u,:]$ is the latent feature vector of user $u$.
    
- $Q[:,i]$ is the latent feature vector of item $i$.
    
- $P[u,:] \cdot Q[:,i]$ is the predicted rating.
    
- $\lambda$ is the regularization parameter, which penalizes excessively large model parameters.
    
- $\|P\|_F^2$ and $\|Q\|_F^2$ are the squared Frobenius norms of the matrices, corresponding to the sums of the squares of all their elements.
    
- $\Omega$ denotes the set of observed user–item interactions.
    

The prediction-error summation is evaluated only over interactions for which actual ratings are available.

### Why Do We Square the Prediction Error?

For a particular observed interaction, define the prediction error as:

\[ e_{u,i} = R[u,i] - P[u,:] \cdot Q[:,i] \]

This represents the difference between the actual rating and the model's prediction.

A positive error indicates that the model underestimated the rating, while a negative error indicates that it overestimated the rating.

If these errors were summed without modification, positive and negative values could cancel each other out, producing an artificially small total error.

Squaring the error prevents this cancellation:

$$ e_{u,i}^{2} = \left(R[u,i] - P[u,:] \cdot Q[:,i]\right)^{2} $$

Squaring also gives larger prediction errors disproportionately greater influence on the loss.

To improve prediction performance and reduce overfitting, the loss function additionally includes a regularization term based on the squared magnitudes of the learned parameters.

## What Is Regularization, and Why Is It Necessary?

Imagine a recommendation model that memorizes individual training ratings rather than learning general patterns of user preferences.

For example, instead of discovering that a user generally prefers science-fiction movies with philosophical themes, the model might adjust its parameters specifically to reproduce a recorded rating of `5` for a particular interaction.

To achieve this exact prediction, the model might learn unusually large values for certain user and item latent features. Such values may work well for the specific training interaction but fail to generalize to other observations.

This phenomenon is known as overfitting.

An overfitted model may achieve excellent performance on its training data while performing poorly on previously unseen interactions. Instead of learning stable relationships between users and items, it captures noise and details specific to the training observations.

Regularization addresses this problem by introducing an additional penalty into the loss function.

The penalty increases with the magnitudes of the model parameters. Consequently, the optimization algorithm is encouraged not only to minimize prediction error but also to avoid unnecessarily large latent feature values.

The regularization parameter $\lambda$ determines the relative importance of this penalty.

- A very small $\lambda$ may provide insufficient regularization, increasing the risk of overfitting.
    
- A very large $\lambda$ may constrain the model excessively, preventing it from learning meaningful patterns and causing underfitting.
    
- An appropriately selected $\lambda$ balances prediction accuracy and model complexity.
    

Through this mechanism, regularization encourages the model to learn more stable and generalizable patterns rather than memorizing individual training examples.

This generally improves the reliability of predictions for previously unobserved user–item interactions.
