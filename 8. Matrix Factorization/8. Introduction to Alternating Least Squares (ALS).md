
In the previous section, we introduced the **Funk-SVD algorithm**, which uses **Stochastic Gradient Descent (SGD)** to learn the user latent-factor matrix $P$, the item latent-factor matrix $Q$, and their associated bias terms.

Although Funk-SVD is an effective matrix factorization algorithm, SGD may converge slowly, and implementing efficient parallel updates can be challenging.

**Alternating Least Squares (ALS)** provides an alternative approach to solving the same optimization problem: minimizing the loss function associated with matrix factorization.

Instead of performing incremental parameter updates, as SGD does, ALS adopts an **alternating optimization strategy** in which one set of model parameters is held fixed while the other is optimized.

This approach is particularly suitable for large-scale recommendation systems and parallel or distributed computing environments.

## Alternating Optimization

The fundamental challenge in matrix factorization is to simultaneously determine the matrices $P$ and $Q$, together with any bias parameters, such that the loss function is minimized.

This is a **non-convex optimization problem** because the predicted ratings depend on products of unknown user and item latent factors. Consequently, jointly optimizing both matrices is generally difficult.

The central idea of ALS is to divide this optimization problem into two simpler subproblems and solve them alternately.

### Step 1: Optimize User Latent Factors

Hold the item latent-factor matrix $Q$ and the item bias terms fixed.

Under this condition, the unknown parameters are:

- The elements of the user latent-factor matrix $P$.
- The user bias terms, if included in the model.

Because $Q$ is fixed, the loss function becomes a **quadratic function** of the unknown user parameters.

For a squared-error objective with L2 regularization, this subproblem is convex and can be solved using regularized least squares.

### Step 2: Optimize Item Latent Factors

Hold the user latent-factor matrix $P$ and the user bias terms fixed.

The unknown parameters are now:

- The elements of the item latent-factor matrix $Q$.
- The item bias terms, if included in the model.

With $P$ fixed, the loss function is quadratic with respect to the unknown item parameters.

This subproblem can also be solved using regularized least squares.

### Alternating Between the Two Steps

ALS typically begins by initializing $P$ and $Q$ with small random values.

It then repeatedly performs the following operations:

1. Fix $Q$ and optimize $P$.
2. Fix $P$ and optimize $Q$.
3. Repeat until a stopping criterion is satisfied.

Each optimization step minimizes the objective with respect to one parameter block while keeping the other fixed.

For exact solutions of the regularized subproblems, the loss function cannot increase after an alternating update. However, because the original joint optimization problem is non-convex, ALS is not guaranteed to find the global minimum.

## The ALS Loss Function

Like other machine learning algorithms, ALS learns its parameters by minimizing a **loss function**, which measures the discrepancy between model predictions and observed data.

In matrix factorization, the objective typically contains two components:

1. **Sum of Squared Errors (SSE):** Measures prediction errors over observed user–item interactions.
2. **L2 Regularization:** Penalizes excessively large latent-factor values to reduce overfitting.

### Mathematical Notation

Consider the following definitions:

- $R$: The user–item interaction matrix of dimensions $m \times n$, where $m$ is the number of users and $n$ is the number of items.

- $R_{u,i}$: The observed interaction value, such as a rating, assigned by user $u$ to item $i$.

- $\Omega$: The set of observed user–item pairs $(u,i)$. For explicit-rating datasets, this set identifies known ratings and must distinguish missing interactions from observed ratings whose values may be zero.

- $P$: The user latent-factor matrix of dimensions $m \times k$, where $k$ is the number of latent factors.

- $P_{u,:}$: The latent-factor vector associated with user $u$, corresponding to row $u$ of $P$.

- $Q$: The item latent-factor matrix of dimensions $n \times k$.

- $Q_{i,:}$: The latent-factor vector associated with item $i$, corresponding to row $i$ of $Q$.

- $\hat{R}_{u,i}$: The predicted rating of user $u$ for item $i$.

- $\lambda$: The nonnegative regularization parameter controlling the strength of the L2 penalty.

Without bias terms, the predicted rating is calculated using the dot product of the corresponding latent-factor vectors:

$$
\hat{R}_{u,i}=P_{u,:}Q_{i,:}^{T}
$$

Equivalently, using vector notation:

$$
\hat{R}_{u,i}=p_{u}^{T}q_{i}
$$

Here, $p_u$ and $q_i$ represent the user and item latent factors as column vectors.

> **Important: Matrix Orientation**
>
> In this section, the item latent-factor matrix $Q$ has dimensions $n \times k$, so each item is represented by a row.
>
> An alternative convention defines $Q$ with dimensions $k \times n$, where each item is represented by a column.
>
> Under the row-based convention:
>
> $$
> \hat{R}_{u,i}=P_{u,:}Q_{i,:}^{T}
> $$
>
> Under the column-based convention:
>
> $$
> \hat{R}_{u,i}=P_{u,:}Q_{:,i}
> $$
>
> Both conventions describe the same underlying matrix factorization model. The distinction is purely a matter of matrix orientation.

### Loss Function Without Bias Terms

The standard regularized squared-error objective for explicit-feedback matrix factorization is:

$$
L(P,Q)=\sum_{(u,i)\in\Omega}(R_{u,i}-P_{u,:}Q_{i,:}^{T})^{2}+\lambda\left(\sum_{u=1}^{m}\lVert P_{u,:}\rVert_{2}^{2}+\sum_{i=1}^{n}\lVert Q_{i,:}\rVert_{2}^{2}\right)
$$

This objective contains two components.

#### 1. Sum of Squared Errors

The first component is:

$$
\sum_{(u,i)\in\Omega}(R_{u,i}-P_{u,:}Q_{i,:}^{T})^{2}
$$

It measures the total squared prediction error across all observed interactions.

For each observed user–item pair, the prediction error is:

$$
e_{u,i}=R_{u,i}-\hat{R}_{u,i}
$$

Substituting the matrix factorization prediction:

$$
e_{u,i}=R_{u,i}-P_{u,:}Q_{i,:}^{T}
$$

Squaring these errors and summing them over the observed interactions gives the total squared error.

Minimizing this component encourages the model to produce predictions that closely approximate the observed ratings.

Only interactions belonging to $\Omega$ contribute to this error term. Missing ratings are not treated as observed zero ratings.

#### 2. L2 Regularization

The second component is:

$$
\lambda\left(\sum_{u=1}^{m}\lVert P_{u,:}\rVert_{2}^{2}+\sum_{i=1}^{n}\lVert Q_{i,:}\rVert_{2}^{2}\right)
$$

This is the **L2 regularization penalty**.

For a user latent-factor vector:

$$
P_{u,:}=[p_{u,1},p_{u,2},\ldots,p_{u,k}]
$$

Its squared L2 norm is:

$$
\lVert P_{u,:}\rVert_{2}^{2}=\sum_{f=1}^{k}p_{u,f}^{2}
$$

Similarly, for an item latent-factor vector:

$$
\lVert Q_{i,:}\rVert_{2}^{2}=\sum_{f=1}^{k}q_{i,f}^{2}
$$

The regularization term penalizes large values in the latent-factor matrices.

Without regularization, a model with sufficient flexibility may fit the observed ratings extremely closely while generalizing poorly to interactions that were not included in the training data.

Regularization discourages unnecessarily large parameter values and helps reduce this tendency toward **overfitting**.

The parameter $\lambda$ controls the trade-off between fitting observed interactions and limiting model complexity:

- A smaller $\lambda$ places greater emphasis on minimizing training errors.
- A larger $\lambda$ imposes stronger penalties on large latent-factor values.
- Setting $\lambda=0$ removes the regularization penalty entirely.

The appropriate value is generally selected using validation data.

## Loss Function with Bias Terms

The basic matrix factorization model can be extended to account for systematic differences between users and items.

For example, some users consistently assign higher ratings than others, while certain items receive higher ratings across the user population.

These tendencies can be represented using bias terms.

The predicted rating becomes:

$$
\hat{R}_{u,i}=\mu+b_{u}+b_{i}+P_{u,:}Q_{i,:}^{T}
$$

Where:

- $\mu$ is the global mean of observed ratings.
- $b_u$ is the bias associated with user $u$.
- $b_i$ is the bias associated with item $i$.
- $P_{u,:}Q_{i,:}^{T}$ captures the interaction between the user's and item's latent factors.

The corresponding regularized loss function is:

$$
L(P,Q,b_u,b_i)=\sum_{(u,i)\in\Omega}\left(R_{u,i}-(\mu+b_u+b_i+P_{u,:}Q_{i,:}^{T})\right)^{2}+\lambda\left(\sum_{u=1}^{m}b_u^{2}+\sum_{i=1}^{n}b_i^{2}+\sum_{u=1}^{m}\lVert P_{u,:}\rVert_{2}^{2}+\sum_{i=1}^{n}\lVert Q_{i,:}\rVert_{2}^{2}\right)
$$

In this expression, the regularization penalty includes both the latent-factor vectors and the bias parameters.

Specifically:

- $\sum_{u=1}^{m}b_u^{2}$ penalizes large user biases.
- $\sum_{i=1}^{n}b_i^{2}$ penalizes large item biases.
- $\sum_{u=1}^{m}\lVert P_{u,:}\rVert_{2}^{2}$ regularizes user latent factors.
- $\sum_{i=1}^{n}\lVert Q_{i,:}\rVert_{2}^{2}$ regularizes item latent factors.

The global mean $\mu$ is typically calculated from the observed ratings and treated as fixed during optimization.

ALS alternately optimizes the user and item latent factors, together with their corresponding bias parameters when biases are included, to minimize this objective.

## Why Is It Called Least Squares?

The term **Least Squares** refers to the mathematical optimization problem that arises when one latent-factor matrix is held fixed.

Suppose the item latent-factor matrix $Q$ is fixed.

For a particular user $u$, the predicted rating depends linearly on the unknown user latent factors:

$$
\hat{R}_{u,i}=P_{u,:}Q_{i,:}^{T}
$$

Because the prediction is linear in $P_{u,:}$, its squared error is a quadratic function of the user latent factors.

Consequently, minimizing the sum of squared prediction errors becomes a standard **least-squares problem**.

Least-squares problems can be solved using linear algebra techniques, including matrix multiplication and linear system solvers.

Unlike SGD, which gradually updates parameters using gradients, ALS solves each least-squares subproblem directly.

For sufficiently small latent-factor dimensions, these subproblems can be solved efficiently.

In practical implementations, linear systems are usually solved using numerically stable factorization methods rather than explicitly computing matrix inverses.

This distinction becomes particularly important when the coefficient matrices are ill-conditioned or when numerical precision is limited.

## Steps of the ALS Algorithm

The ALS training procedure consists of initialization, alternating optimization, and convergence checking.

### 1. Initialization

First, select the number of latent factors $k$.

Initialize the user latent-factor matrix:

$$
P\in\mathbb{R}^{m\times k}
$$

Initialize the item latent-factor matrix:

$$
Q\in\mathbb{R}^{n\times k}
$$

Both matrices are typically initialized using small random values.

If the model includes bias terms:

- Initialize `user_bias` with zeros.
- Initialize `item_bias` with zeros.
- Calculate `global_average` from the observed ratings.

Next, specify the regularization parameter $\lambda$ and the maximum number of training iterations.

### 2. Alternating Iteration

For a specified number of epochs, repeat the following two optimization steps.

#### Step A: Solve for P While Holding Q Fixed

For each user $u$, independently solve a least-squares problem to estimate the user latent-factor vector:

$$
P_{u,:}
$$

If user biases are included, the corresponding bias parameter is also optimized.

This calculation uses:

- All observed ratings associated with user $u$.
- The fixed latent-factor vectors of the items rated by user $u$.
- The relevant item bias terms, if applicable.

The resulting solution replaces the current latent-factor vector for user $u$.

Because each user's optimization problem is independent when item parameters are fixed, user updates can be performed in parallel.

#### Step B: Solve for Q While Holding P Fixed

For each item $i$, independently solve a least-squares problem to estimate the item latent-factor vector:

$$
Q_{i,:}
$$

If item biases are included, the corresponding item bias is also optimized.

This calculation uses:

- All observed ratings associated with item $i$.
- The fixed latent-factor vectors of users who rated that item.
- The relevant user bias terms, if applicable.

The resulting solution replaces the current latent-factor vector for item $i$.

As in the user-update step, the individual item optimization problems can be solved in parallel.

### 3. Convergence

ALS stops when one of the following conditions is satisfied:

1. The maximum number of epochs has been reached.
2. The change in the loss function becomes sufficiently small.
3. The changes in the latent-factor matrices become negligible.

Although each exact alternating minimization step does not increase the objective, convergence to a globally optimal solution is not guaranteed because the joint matrix factorization problem is non-convex.
