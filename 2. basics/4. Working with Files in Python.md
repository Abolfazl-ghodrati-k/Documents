## Introduction

In virtually every programming project—and especially in data mining, machine learning, and recommender systems—the first step is often reading data from files, while the final step involves storing results, models, or processed datasets back to files.

A recommender system may need to load user ratings, item metadata, learned embeddings, or trained model parameters from disk. Likewise, recommendations, evaluation results, and trained models often need to be saved for future use.

In this chapter, we will explore the most common file formats encountered in data science and learn how to work with them using Python, Pandas, and NumPy.

---

# Opening and Closing Files

Before Python can read from or write to a file, it must first open that file. This is accomplished using Python's built-in `open()` function.

The function accepts two primary arguments:

1. The file path
2. The file opening mode

Different tasks require different file modes.

## Common File Modes

|Mode|Description|
|---|---|
|`r`|Read mode (default)|
|`w`|Write mode (creates a new file or overwrites an existing one)|
|`a`|Append mode (adds content to the end of an existing file)|
|`b`|Binary mode|
|`t`|Text mode (default)|
|`+`|Update mode (allows both reading and writing)|

For example, if the goal is simply to read a file, opening it in read mode (`r`) is the safest option because it prevents accidental modifications.

### Writing to a File

```python
file = open('example.txt', 'w')

file.write('Hello World.\nWelcome to Recommender Systems Course!')

file.close()
```

After finishing file operations, it is important to close the file using the `close()` method. Closing files releases system resources and ensures that all changes are properly written to disk.

---

# Using the `with` Statement

Python provides a more elegant and safer way to work with files through the `with` statement.

```python
with open('example.txt', 'w') as file:
    file.write('Hello World.\nWelcome to Recommender Systems Course!')
```

The `with` statement automatically closes the file when the block finishes execution, even if an exception occurs. This prevents resource leaks and reduces the risk of losing unsaved data.

For this reason, the `with` statement is considered the preferred approach for file handling in Python.

# Reading Files

Python provides several methods for reading file contents. The most common are:

- `read()`
- `readline()`
- `readlines()`

Each method serves a different purpose.

---

## Reading an Entire File

The `read()` method loads the entire contents of a file into memory.

```python
with open('example.txt', 'r') as file:
    content = file.read()
    print(content)
```

Output:

```text
Hello World.
Welcome to Recommender Systems Course!
```

This method is convenient for small files but may be inefficient when working with very large datasets.

---

## Reading One Line at a Time

The `readline()` method reads a single line during each call.

```python
with open('example.txt', 'r') as file:
    line = file.readline()
    line_number = 1

    while line:
        print(f'Line {line_number}:')
        print(line)

        line_number += 1
        line = file.readline()
```

Output:

```text
Line 1:
Hello World.

Line 2:
Welcome to Recommender Systems Course!
```

Reading line by line is often more memory-efficient than loading the entire file at once.

---

## Reading All Lines into a List

The `readlines()` method reads every line and stores them in a Python list.

```python
with open('example.txt', 'r') as file:
    lines = file.readlines()

    for line in lines:
        print(line, end='')
```

Output:

```text
Hello World.
Welcome to Recommender Systems Course!
```

This approach is useful when individual lines need to be processed separately.

---

# Writing to Files

The `write()` method allows us to store text inside a file.

```python
with open('example.txt', 'w') as file:
    file.write("Hello, World!\n")
    file.write("This is a new line.\n")
```

If we read the file afterward, we obtain:

```text
Hello, World!
This is a new line.
```

Notice that the previous contents of the file have disappeared.

This occurs because the `w` mode overwrites existing files.

---

## Appending to a File

If we wish to preserve existing content and add new text to the end of the file, we should use append mode (`a`).

```python
with open('example.txt', 'a') as file:
    file.write("Welcome to Recommender Systems.\n")
```

Reading the file again produces:

```text
Hello, World!
This is a new line.
Welcome to Recommender Systems.
```

The new line has been added without modifying the previous contents.

# Handling Exceptions

File operations are prone to various errors.

For example:

- The file may not exist.
    
- The user may not have permission to access it.
    
- The disk may be unavailable.
    
- A directory may be mistakenly treated as a file.
    

Python handles such situations through exceptions.

```python
try:
    with open('example.txt', 'r') as file:
        content = file.read()
        print(content)

except FileNotFoundError:
    print("File not found.")

except IOError:
    print("Error reading file.")
```

Exception handling allows programs to fail gracefully instead of crashing unexpectedly.

---

## Common File-Related Exceptions

|Exception|Description|
|---|---|
|`FileNotFoundError`|Raised when the specified file cannot be found.|
|`IOError`|Raised when an input/output operation fails.|
|`PermissionError`|Raised when the program lacks sufficient access permissions.|
|`IsADirectoryError`|Raised when a directory is used where a file is expected.|
|`OSError`|General operating system-related file error.|

Understanding these exceptions is essential for building reliable data-processing pipelines.

# Working with CSV and TSV Files Using Pandas

Most recommender system datasets are stored in tabular formats.

Two of the most common formats are:

- **CSV (Comma-Separated Values)**
    
- **TSV (Tab-Separated Values)**
    

These formats are widely used because they are simple, portable, and easy to inspect.

Pandas provides powerful tools for reading and writing such files and converting them directly into DataFrames.

---

## Creating Example Datasets

Consider the following sample CSV file containing user ratings:

```python
csv_content = """user_id,item_id,rating,timestamp
1,101,5,1678886400
1,102,4,1678886460
2,101,4,1678886520
2,103,5,1678886580
3,102,3,1678886640
3,103,4,1678886700
3,104,5,1678886760
"""

with open("ratings_example.csv", "w") as f:
    f.write(csv_content)
```

Similarly, a TSV file can be used to store movie information:

```python
tsv_content = """item_id\ttitle\tgenres
101\tToy Story\tAnimation|Children|Comedy
102\tJumanji\tAdventure|Children|Fantasy
103\tGrumpier Old Men\tComedy|Romance
104\tWaiting to Exhale\tComedy|Drama|Romance
"""

with open("movies_example.tsv", "w") as f:
    f.write(tsv_content)
```

---

## Reading CSV Files

Pandas can load CSV files directly into a DataFrame.

```python
import pandas as pd

ratings_df = pd.read_csv("ratings_example.csv")
```

To preview the data:

```python
ratings_df.head()
```

Output:

```text
   user_id  item_id  rating   timestamp
0        1      101       5  1678886400
1        1      102       4  1678886460
2        2      101       4  1678886520
3        2      103       5  1678886580
4        3      102       3  1678886640
```

---

## Reading TSV Files

Since TSV files use tabs instead of commas, we specify the separator explicitly.

```python
movies_df = pd.read_csv(
    "movies_example.tsv",
    sep='\t'
)
```

```python
movies_df.head()
```

Output:

```text
   item_id              title                      genres
0      101          Toy Story   Animation|Children|Comedy
1      102            Jumanji  Adventure|Children|Fantasy
2      103   Grumpier Old Men              Comedy|Romance
3      104  Waiting to Exhale        Comedy|Drama|Romance
```

# Exploring Data with `head()` and `tail()`

Large datasets often contain millions of rows.

Pandas provides two convenient methods for quick inspection:

- `head()` — displays the first rows
    
- `tail()` — displays the last rows
    

```python
ratings_head = ratings_df.head()

movies_tail = movies_df.tail(3)
```

These methods are particularly useful during exploratory data analysis.

---

# Saving DataFrames to Files

DataFrames can be written back to disk using `to_csv()`.

```python
ratings_head.to_csv(
    'rating_sample.csv',
    index=False
)
```

For TSV files:

```python
movies_tail.to_csv(
    'movies_sample.tsv',
    index=False,
    sep='\t'
)
```

---

## Important Parameters in `read_csv()` and `to_csv()`

|Parameter|Description|
|---|---|
|`sep`|Column separator character|
|`header`|Indicates whether column names are present|
|`names`|Custom column names|
|`dtype`|Specifies data types for columns|
|`index`|Determines whether DataFrame indices should be saved|

Understanding these parameters provides greater control over data import and export operations.

# Working with NPZ Files Using NumPy

In many machine learning projects, certain computations are expensive and time-consuming.

For example:

- Matrix factorization
    
- User embeddings
    
- Item embeddings
    
- Feature extraction
    

Repeating these computations every time a project is reopened can be extremely inefficient.

Instead, we can save the computed arrays and load them later.

NumPy's **NPZ format** is specifically designed for storing one or more NumPy arrays efficiently in a compressed binary format.

---

## Saving Arrays

Suppose we have latent factor matrices learned by a recommender system.

```python
import numpy as np

user_latent_factors = np.random.rand(100, 20)

item_latent_factors = np.random.rand(500, 20)

np.savez_compressed(
    "latent_factors_data.npz",
    users=user_latent_factors,
    items=item_latent_factors
)
```

The arrays are stored using descriptive names (`users` and `items`), making them easy to retrieve later.

---

## Loading Arrays

Stored arrays can be loaded using `np.load()`.

```python
loaded_data = np.load(
    "latent_factors_data.npz"
)

loaded_user_factors = loaded_data['users']

loaded_item_factors = loaded_data['items']
```

After usage, the file should be closed:

```python
loaded_data.close()
```

We can verify the loaded data:

```python
print(
    loaded_user_factors.shape
)

print(
    loaded_item_factors.shape
)
```

Output:

```text
(100, 20)
(500, 20)
```

# Best Practices for File Handling

When working with files in data science projects, it is recommended to:

1. Use `with` statements whenever possible.
    
2. Handle exceptions gracefully.
    
3. Choose appropriate file formats for different tasks.
    
4. Avoid loading large files entirely into memory unless necessary.
    
5. Close resources after use.
    
6. Save expensive intermediate results to avoid recomputation.
