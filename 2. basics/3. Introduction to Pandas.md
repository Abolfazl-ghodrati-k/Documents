## NumPy: The Backbone of Pandas

In the previous chapter, we explored **NumPy**, a powerful library for working with numerical arrays and performing linear algebra operations.

Pandas is built directly on top of NumPy. Its primary data structures—**Series** and **DataFrame**—use NumPy arrays as their underlying building blocks. Pandas extends NumPy by adding additional capabilities such as:

- Row and column labels
- Handling missing values
- Advanced data manipulation tools
- Flexible indexing and selection operations    

This close relationship between Pandas and NumPy provides two major advantages:

### Performance

Since Pandas relies on NumPy's highly optimized array operations, it benefits from exceptional computational efficiency when processing large datasets.

### Interoperability

Data can be transferred seamlessly between Pandas and NumPy structures, making it easy to combine the strengths of both libraries within the same workflow.

# Getting Started with Pandas

The first data structure we encounter in Pandas is the **Series**.

A Series can be thought of as a one-dimensional labeled array. It resembles a column in a spreadsheet or a vector in NumPy, with one important distinction: each element is associated with a label called an **index**.

---

## Components of a Series

A Pandas Series consists of three primary components:

### Data

The actual values stored within the Series. These values may be numbers, strings, dates, Python objects, and more.

### Index

Labels associated with each data element. If no index is explicitly provided, Pandas automatically assigns integer indices beginning at zero.

### Data Type (dtype)

The type of data stored in the Series, similar to NumPy's `dtype`.

---

## Creating a Series

A Series can be created from various sources, including Python lists, NumPy arrays, and dictionaries.

The simplest approach is to construct a Series from a Python list:

```python
import pandas as pd
import numpy as np

s_int = pd.Series([1, 2, 3, 4, 5])

s_float = pd.Series([1.1, 2.2, 3.3, 4.4])

s_str = pd.Series(["parsa", "parto", "hamed", "sajjad"])
```

---

## Understanding Indexes

Consider the following example:

```python
s = pd.Series([-1, 4, -3])

s
```

Output:

```text
0   -1
1    4
2   -3
dtype: int64
```

The values on the left (`0`, `1`, and `2`) are the Series indices. Pandas automatically generates these labels when none are provided by the user.

The index can be accessed directly using the `index` attribute:

```python
s.index
```

Output:

```text
RangeIndex(start=0, stop=3, step=1)
```

This special index type is known as a **RangeIndex**, representing a sequence of consecutive integers.

---

## Accessing the Underlying Values

The actual data stored within a Series can be retrieved using the `values` attribute:

```python
s.values
```

Output:

```python
array([-1, 4, -3])
```

Because Pandas is built upon NumPy, the returned object is a NumPy array.

```python
type(s.values)
```

Output:

```python
numpy.ndarray
```

---

## Using NumPy Functions with Series

Since the underlying data is stored as NumPy arrays, many NumPy functions can be applied directly to a Series.

For example:

```python
np.max(s)
```

Output:

```python
4
```

It is important to note that such operations act on the data values rather than on the index labels. The index serves primarily for identification and alignment purposes.

---

## Converting a Series to a Python List

Pandas also provides convenient methods for converting data into native Python objects.

```python
s.to_list()
```

Output:

```python
[-1, 4, -3]
```

---

## Custom Indexing

So far, all Series have used automatically generated indices. However, Pandas allows users to define their own labels.

```python
s = pd.Series([19, 16, 20], index=["a", "b", "c"])

s
```

Output:

```text
a    19
b    16
c    20
dtype: int64
```

The index can also be modified after the Series has been created:

```python
s.index = ['ali', 'gholi', 'vali']

s
```

Output:

```text
ali      19
gholi    16
vali     20
dtype: int64
```

---

## Creating a Series from a Dictionary

In addition to arrays and lists, Pandas can construct a Series directly from a Python dictionary.

```python
purity_dictionary = {
    "Ali": 19,
    "Gholi": 16,
    "Vali": 20
}

purity_series = pd.Series(purity_dictionary)

purity_series
```

Output:

```text
Ali      19
Gholi    16
Vali     20
dtype: int64
```

Notice that the dictionary keys automatically become the index labels, while the dictionary values become the Series data.

# Element-Wise Operations on Series

Because a Series is built upon NumPy arrays, mathematical and logical operations are performed element by element.

Consider the following example:

```python
user_ratings_dict = {
    'Movie A': 4.5,
    'Movie B': 3.0,
    'Movie C': 5.0,
    'Movie D': 2.5
}

user_ratings_series = pd.Series(user_ratings_dict)
```

### Adding a Constant

```python
added_value_series = user_ratings_series + 0.5
```

Result:

```text
Movie A    5.0
Movie B    3.5
Movie C    5.5
Movie D    3.0
dtype: float64
```

### Multiplying by a Constant

```python
scaled_series = user_ratings_series * 2
```

Result:

```text
Movie A     9.0
Movie B     6.0
Movie C    10.0
Movie D     5.0
dtype: float64
```

---

## Operations Between Two Series

Now consider another user's ratings:

```python
another_user_ratings = pd.Series({
    'Movie B': 4.0,
    'Movie C': 3.5,
    'Movie E': 4.5
})
```

Adding the two Series together:

```python
combined_ratings = user_ratings_series + another_user_ratings
```

Result:

```text
Movie A    NaN
Movie B    7.0
Movie C    8.5
Movie D    NaN
Movie E    NaN
dtype: float64
```

---

## Automatic Alignment by Index

One of the most powerful features of Pandas is **automatic index alignment**.

When operations are performed between two Series objects, Pandas matches values based on their index labels rather than their positions.

In the previous example:

- `Movie B` exists in both Series, so the values are added.
- `Movie C` exists in both Series, so the values are added.
- `Movie A` and `Movie D` appear only in the first Series.
- `Movie E` appears only in the second Series.    

Whenever an index is missing from one of the Series, Pandas returns **NaN** (_Not a Number_), indicating missing data.

This automatic alignment mechanism is one of Pandas' defining features and greatly simplifies the handling of real-world datasets, where missing values and inconsistent records are common.
