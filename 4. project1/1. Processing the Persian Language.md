### Installing and Using the Hazm Library

The **Hazm** library is one of the most widely used tools for **Natural Language Processing (NLP)** in Persian. It provides a comprehensive collection of utilities for processing Persian text, including **tokenization**, **normalization**, **stemming**, **lemmatization**, and several other preprocessing tasks.

Throughout this course, Hazm will be used to prepare Persian text for recommendation systems and other NLP applications. This section introduces the library's core features and demonstrates how to use them effectively.

## Installing the Library

Before using Hazm, install it with the following command:

```
pip install hazm
```

## Text Normalization

**Normalization** is the process of converting different writing styles and spelling variations into a standardized form. Persian text often contains inconsistencies such as varying whitespace, different Unicode representations of characters, or inconsistent punctuation. Normalization ensures that these inconsistencies are removed, resulting in cleaner and more uniform text.

Hazm performs normalization through the `Normalizer` class.

```
from hazm import Normalizer

normalizer = Normalizer()

text = 'کتابخانه‌ ی حزم، برای پردازش زبان فارسی بهتر میباشد.'
normalized_text = normalizer.normalize(text)

print(normalized_text)
```

**Output**

```
'کتابخانه‌ی هضم، برای پردازش زبان فارسی بهتر می‌باشد.'
```

The normalizer automatically corrects common formatting issues, such as:

- Standardizing spacing between words.
- Correcting half-spaces (Zero-Width Non-Joiner).
- Normalizing Unicode characters.
- Fixing common orthographic inconsistencies.

## Tokenization

One of the first steps in any NLP pipeline is **tokenization**, which divides text into smaller units called **tokens**. Depending on the task, tokens may represent words, sentences, or phrases.

Hazm provides the `WordTokenizer` class for word-level tokenization.

```
from hazm import WordTokenizer

tokenizer = WordTokenizer()

text = 'کتابخانه حزم برای پردازش زبان فارسی بهتر است'
tokens = tokenizer.tokenize(text)

print(tokens)
```

**Output**

```
['کتابخانه', 'حزم', 'برای', 'پردازش', 'زبان', 'فارسی', 'بهتر', 'است']
```

The resulting list of tokens can then be used as input for subsequent NLP tasks such as feature extraction, vectorization, or text classification.

## Stemming

**Stemming** is the process of reducing words to their root form by removing prefixes or suffixes without considering the precise linguistic meaning of the word. Because stemming is based on simple heuristic rules, the resulting stem may not always be a valid dictionary word.

Hazm performs stemming using the `Stemmer` class.

```
from hazm import Stemmer

stemmer = Stemmer()

words = ['کشیدی', 'خواندند', 'رفتم']
stemmed_words = [stemmer.stem(word) for word in words]

print(stemmed_words)
```

**Output**

```
['کشید', 'خواندند', 'رف']
```

Notice that the produced stems are simplified forms of the original words and are not necessarily linguistically complete. Despite this limitation, stemming is computationally efficient and is widely used in information retrieval and search systems.

## Lemmatization

Many NLP tasks require converting words into their **lemma**, or canonical dictionary form, rather than simply removing affixes. Unlike stemming, **lemmatization** considers the linguistic structure and meaning of words, producing more meaningful base forms.

Hazm provides the `Lemmatizer` class for this purpose.

```
from hazm import Lemmatizer

lemmatizer = Lemmatizer()

words = ['رفتیم', 'خواندم', 'کتاب']
lemmatized_words = [lemmatizer.lemmatize(word) for word in words]

print(lemmatized_words)
```

**Output**

```
['رفت#رو', 'خواند#خوان', 'کتاب']
```

For verbs, Hazm returns both the **past stem** and the **present stem**, separated by the `#` character. For example:

- `رفت#رو`
- `خواند#خوان`

This representation preserves the morphological relationship between different verb forms and is particularly useful in advanced NLP applications such as text analysis, semantic search, and recommendation systems.
