So far, we have organized user-item interactions into a user-item matrix and constructed an item-item similarity matrix with appropriate similarity measures. This matrix contains information about how items relate to one another from the users' perspective. We can now use these two matrices to predict a user's rating for an unseen item and generate a personalized recommendation list.

## 1. The Logic of Rating Prediction in IBCF

Rating prediction in IBCF rests on a simple but powerful principle: a user's past preferences can help predict their future preferences when relationships among items are known.

More specifically:

- Items that a user rated highly represent aspects of that user's preference profile.
- To predict the user's rating for an unseen item, we examine how similar that item is to items the user has already rated.
- The more similar the unseen item is to an item the user liked, and the higher the user's rating for that known item, the higher the predicted rating is likely to be.

The predicted rating is therefore a weighted average of the user's ratings for similar items, where each weight is the similarity between a previously rated item and the target item.

Unlike UBCF, which searches for similar users, this approach works directly with item-item relationships. These relationships are often more stable than user-user relationships.

## 2. The Rating-Prediction Procedure

Suppose that we want to predict the rating that user $U$ would assign to item $j$, which user $U$ has not yet rated. The process consists of the following steps.

### Extract the User Interaction History

First, identify all items that user $U$ has already interacted with and rated. Denote this set by $I_{U}$. This set is the basis for understanding the user's preferences. For each item $i\in I_{U}$, the rating $r_{Ui}$ assigned by user $U$ is also available.

### Measure Similarity Between the Target Item and the User History

For each item $i\in I_{U}$, consult the item-item similarity matrix to obtain the similarity between target item $j$ and item $i$:

$$sim(j,i)$$

This value indicates how closely the target item resembles an item that user $U$ previously rated.

### Select Influential Neighbors

Not every item in $I_{U}$ should necessarily have equal influence on the prediction for $j$. The items most similar to $j$ are generally the most informative. We therefore choose a set of influential item neighbors, denoted by $N_{j}$.

Common selection strategies include:

- **$K$-nearest neighbors:** Select the $K$ items in $I_{U}$ with the largest similarity values to $j$. Here, $K$ is an important hyperparameter. A very small $K$ may discard useful evidence, whereas a very large $K$ may introduce noise.
- **Similarity threshold:** Define a threshold, such as $sim(j,i)>0.1$, and retain only items whose similarity to $j$ exceeds that threshold.
- **All related items:** When the user has rated few items, use all items in $I_{U}$ for which $sim(j,i)$ is defined and nonzero, or only positive depending on the similarity policy.

### Compute the Predicted Rating with a Weighted Average

The predicted rating for item $j$ is usually calculated as a weighted average of the user's ratings for neighboring items:

$$pred(U,j)=\frac{\sum_{i\in N_{j}}sim(j,i)\cdot r_{Ui}}{\sum_{i\in N_{j}}\lvert sim(j,i)\rvert}$$

where:

- $pred(U,j)$ is user $U$'s predicted rating for item $j$.
- $N_{j}$ is the set of neighbor items similar to $j$ that user $U$ has rated.
- $sim(j,i)$ is the similarity between target item $j$ and neighbor item $i$.
- $r_{Ui}$ is the rating that user $U$ assigned to neighbor item $i$.

The denominator normalizes the weighted sum and helps keep the prediction in a reasonable range. Taking the absolute value is especially relevant when a similarity measure can return negative values. An implementation must define how negative similarities are handled; the example code below deliberately uses only positive similarities.

## 3. Generating Top-$N$ Recommendations

The final goal of a recommender system is to present a short, appealing list of items that the user is likely to value.

1. **Define the candidate set.** It contains items with which user $U$ has not interacted: items not rated, purchased, viewed, or otherwise observed.
2. **Predict a score for every candidate.** Apply the rating-prediction procedure to each candidate item. This can be the most computationally costly stage at recommendation time.
3. **Rank and select the top $N$.** Sort candidates by predicted rating in descending order and select the first $N$ items, such as $N=5$ or $N=10$.

## 4. Worked Example and Python Implementation

Consider the following user-item rating matrix. `NaN` indicates that a rating is unavailable.

| User | Film 1 (F1) | Film 2 (F2) | Film 3 (F3) | Film 4 (F4) |
|---|---:|---:|---:|---:|
| Ali | 5 | 4 | 2 | 3 |
| Sara | 4 | 5 | NaN | NaN |
| Reza | NaN | 2 | 5 | NaN |
| Maryam | NaN | 3 | 4 | 5 |

Assume the following item-item similarity matrix:

|  | F1 | F2 | F3 | F4 |
|---|---:|---:|---:|---:|
| **F1** | 1.00 | 0.66 | 0.20 | 0.50 |
| **F2** | 0.66 | 1.00 | 0.75 | 0.40 |
| **F3** | 0.20 | 0.75 | 1.00 | 0.90 |
| **F4** | 0.50 | 0.40 | 0.90 | 1.00 |

The following runnable example requires Python with the `pandas` and `numpy` packages installed. The similarity values are illustrative inputs; in a production system, they must be computed from training data only, without leaking held-out test interactions into the similarity matrix.

```python
import pandas as pd
import numpy as np

# 1. Define the user-item rating matrix
# Rows are users and columns are items (movies)
data_ratings_dict = {
    'F1': {'Ali': 5.0, 'Sara': 4.0, 'Reza': np.nan, 'Maryam': np.nan},
    'F2': {'Ali': 4.0, 'Sara': 5.0, 'Reza': 2.0, 'Maryam': 3.0},
    'F3': {'Ali': 2.0, 'Sara': np.nan, 'Reza': 5.0, 'Maryam': 4.0},
    'F4': {'Ali': 3.0, 'Sara': np.nan, 'Reza': np.nan, 'Maryam': 5.0}
}
user_item_df = pd.DataFrame(data_ratings_dict)

print("User-Item Matrix:")
print(user_item_df)
print("-" * 30)

# 2. Define the item-item similarity matrix
# Each entry indicates similarity between two items
data_similarity_dict = {
    'F1': {'F1': 1.00, 'F2': 0.66, 'F3': 0.20, 'F4': 0.50},
    'F2': {'F1': 0.66, 'F2': 1.00, 'F3': 0.75, 'F4': 0.40},
    'F3': {'F1': 0.20, 'F2': 0.75, 'F3': 1.00, 'F4': 0.90},
    'F4': {'F1': 0.50, 'F2': 0.40, 'F3': 0.90, 'F4': 1.00}
}
item_similarity_df = pd.DataFrame(data_similarity_dict)

print("Item-Item Similarity Matrix:")
print(item_similarity_df)
print("-" * 30)

# 3. Rating prediction using Item-Based Collaborative Filtering (IBCF)
def predict_rating_ibcf(user_id, item_id_to_predict, user_item_matrix, item_similarity_matrix):
    """
    Predict a user's rating for a specific item using IBCF.
    - user_id: name of the user (e.g., 'Sara')
    - item_id_to_predict: item to predict (e.g., 'F3')
    - user_item_matrix: user-item ratings DataFrame
    - item_similarity_matrix: item-item similarity DataFrame
    """

    # Retrieve ratings given by the user
    user_ratings = user_item_matrix.loc[user_id]

    # Get the items rated by the user (non-NaN)
    rated_items_by_user = user_ratings.dropna()

    # If no rated items or target item not in similarity matrix, return NaN
    if rated_items_by_user.empty or item_id_to_predict not in item_similarity_matrix:
        return np.nan

    numerator = 0
    denominator = 0

    # Loop through rated items to compute weighted sum
    for rated_item_id, rating in rated_items_by_user.items():
        if item_id_to_predict in item_similarity_matrix.index and rated_item_id in item_similarity_matrix.columns:
            similarity = item_similarity_matrix.loc[item_id_to_predict, rated_item_id]

            # Only consider meaningful similarities and exclude the target item itself
            if similarity > 0 and rated_item_id != item_id_to_predict:
                numerator += similarity * rating
                denominator += abs(similarity)

    # If no similar neighbors found, return NaN
    if denominator == 0:
        return np.nan

    predicted_score = numerator / denominator
    return predicted_score

# 4. Generate Top-N item recommendations for a user
def generate_top_n_recommendations_ibcf(user_id, n, user_item_matrix, item_similarity_matrix, all_items_list):
    """
    Generate a ranked list of N recommended items for a user using IBCF.
    - user_id: target user
    - n: number of recommendations
    - user_item_matrix: user-item ratings
    - item_similarity_matrix: item-item similarity matrix
    - all_items_list: list of all items in the system
    """
    user_ratings = user_item_matrix.loc[user_id]
    items_rated_by_user = user_ratings.dropna().index.tolist()

    # Items not yet rated by the user (candidates for recommendation)
    candidate_items = [item for item in all_items_list if item not in items_rated_by_user]

    if not candidate_items:
        print(f"User {user_id} has rated all items or no new items to recommend.")
        return []

    predictions = {}
    for item_id in candidate_items:
        predicted_score = predict_rating_ibcf(user_id, item_id, user_item_matrix, item_similarity_matrix)
        if not pd.isna(predicted_score):
            predictions[item_id] = predicted_score

    # Sort items by predicted score in descending order
    sorted_predictions = sorted(predictions.items(), key=lambda x: x[1], reverse=True)

    return sorted_predictions[:n]

# Full list of items in the system
all_items = user_item_df.columns.tolist()
```

### Predicting Sara's Rating for Film 3

The target user is Sara, and the target item is F3. Sara has rated:

$$r_{\text{Sara},F1}=4$$

$$r_{\text{Sara},F2}=5$$

The similarities to F3 are:

$$sim(F3,F1)=0.20$$

$$sim(F3,F2)=0.75$$

Both items are used as neighbors, so:

$$N_{F3}=\{F1,F2\}$$

The predicted rating is:

$$pred(\text{Sara},F3)=\frac{0.75\cdot5+0.20\cdot4}{0.75+0.20}$$

$$pred(\text{Sara},F3)=\frac{3.75+0.8}{0.95}=\frac{4.55}{0.95}\approx4.789$$

The system therefore predicts that Sara would likely give F3 a high rating, approximately $4.79$.

### Generating Top-2 Recommendations for Reza

Reza has rated:

$$r_{\text{Reza},F2}=2$$

$$r_{\text{Reza},F3}=5$$

The candidate items are $\{F1,F4\}$.

For F1, the relevant similarities are:

$$sim(F1,F2)=0.66,\quad sim(F1,F3)=0.20$$

Thus:

$$pred(\text{Reza},F1)=\frac{0.20\cdot5+0.66\cdot2}{0.20+0.66}=\frac{2.32}{0.86}\approx2.698$$

For F4, the relevant similarities are:

$$sim(F4,F2)=0.40,\quad sim(F4,F3)=0.90$$

Thus:

$$pred(\text{Reza},F4)=\frac{0.90\cdot5+0.40\cdot2}{0.90+0.40}=\frac{5.3}{1.3}\approx4.077$$

Sorting in descending order gives:

1. F4, with predicted rating $4.08$.
2. F1, with predicted rating $2.70$.

## Summary

IBCF predicts an unseen item's rating by combining the target user's ratings for similar, already-rated items. To produce top-$N$ recommendations, the system scores every unseen candidate item, removes already-seen items, ranks the remaining candidates by predicted score, and returns the highest-ranked items. Reliable results depend on meaningful item similarities, suitable neighbor-selection rules, and avoiding leakage by computing similarities solely from training data during offline evaluation.
