## 2.7 Preprocessing the `overview` Column

In the earlier lessons of this chapter, we learned how valuable textual information associated with items can be transformed into meaningful features through text preprocessing.

To preprocess the movie overview, we define the following function:

```python
from nltk.corpus import stopwords
from nltk.stem import WordNetLemmatizer
import re

lemma = WordNetLemmatizer()

stop_words = set(stopwords.words("english"))

def text_preprocess(text):
    text = text.lower()
    text = re.sub(r"[^a-z\s]", "", text)
    words = text.split()
    words = [word for word in words if word not in stop_words]
    words = [lemma.lemmatize(word) for word in words]
    words = [word for word in words if word != ""]
    text = " ".join(words)
    return text
```

## 2.8 Creating the `tags` Feature

All of the preprocessing performed so far has been aimed at constructing a unified representation of each movie based on the available information.

Before combining the features, it is beneficial to remove unnecessary whitespace from the categorical columns. Extra spaces can create inconsistencies by causing semantically identical values to be treated as different tokens.

```python
df["genres"] = df["genres"].apply(lambda x: [i.replace(" ", "") for i in x])
df["keywords"] = df["keywords"].apply(lambda x: [i.replace(" ", "") for i in x])
df["cast"] = df["cast"].apply(lambda x: [i.replace(" ", "") for i in x])
df["crew"] = df["crew"].apply(lambda x: [i.replace(" ", "") for i in x])
```

We are now ready to build the **item profile**.

An item profile is a textual representation that aggregates all informative attributes describing an item, such as:

- Director
- Cast members
- Genres
- Keywords
- Plot summary

Instead of treating these attributes separately, we concatenate them into a single text field named `tags`.

```python
# Concatenate multiple features into a single text representation
df["tags"] = (
    df["crew"]
    + df["cast"]
    + df["genres"]
    + df["keywords"]
    + df["overview"].apply(lambda x: x.split())
)

df["tags"] = df["tags"].apply(lambda x: " ".join(x))
df["tags"] = df["tags"].apply(lambda x: x.lower())
```

# Phase 3: Vectorizing the Data

The `tags` column currently contains textual representations of movies. To enable machine learning algorithms to process these representations, they must be converted into numerical vectors.

As discussed in previous lessons, several text vectorization methods are available. In this project, we use **Term Frequency–Inverse Document Frequency (TF-IDF)** to transform each movie profile into a numerical feature vector.

```python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer()

# Learn the vocabulary and transform the documents
X = vectorizer.fit_transform(df["tags"])
```

After fitting the vectorizer, each movie is represented as a high-dimensional sparse vector.

Displaying the first movie vector yields:

```python
X[0]
```

```
<1x34787 sparse matrix of type ''
    with 43 stored elements in Compressed Sparse Row format>
```

This output indicates that:

- The vocabulary contains **34,787 unique terms**.
- Each movie is represented by a vector of length 34,787.
- Only **43 entries** are non-zero for the first movie, making the representation highly sparse.
- Scikit-learn stores the vectors using the **Compressed Sparse Row (CSR)** format to efficiently represent sparse matrices without wasting memory on zero-valued elements.

# Phase 4: Measuring Similarity

We are now approaching the final stages of the recommendation system.

The next step is to compute the similarity between every pair of movies based on their TF-IDF representations. As discussed in the lesson _Finding Similarities: Simple Mathematics, Powerful Results_, **Cosine Similarity** is an effective metric for comparing document vectors.

The similarity computation is straightforward:

```python
from sklearn.metrics.pairwise import cosine_similarity

cosine_sim = cosine_similarity(X)
```

The resulting matrix, `cosine_sim`, is an $N \times N$ similarity matrix, where $N$ is the number of movies in the dataset.

Each element

$$cosine\_sim_i,_j$$​

represents the cosine similarity between movies $i$ and $j$.

Movies with values close to 1 are highly similar, whereas values near 0 indicate little or no similarity.

# Phase 5: Generating Recommendations

The final step is to implement a function that retrieves the most similar movies given a movie title.

The following function accepts a movie title and returns the five most similar movies according to cosine similarity.

```python
def recommend(movie_name):
    movie_index = df[df["title"] == movie_name].index[0]

    distances = cosine_sim[movie_index]

    recommended_movies_list = sorted(
        list(enumerate(distances)),
        reverse=True,
        key=lambda x: x[1]
    )[1:6]

    for recommended_movie in recommended_movies_list:
        print(df.iloc[recommended_movie[0]].title)
```

The recommendation process consists of four steps:

1. Find the index of the queried movie.
2. Retrieve its similarity scores with every other movie.
3. Sort all movies in descending order of similarity.
4. Ignore the first result (the movie itself) and return the top five remaining movies.
