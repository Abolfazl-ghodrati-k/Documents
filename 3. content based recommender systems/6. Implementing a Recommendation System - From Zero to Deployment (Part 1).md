The values are stored as **string representations of lists of dictionaries**, which are inconvenient for later processing.

For example, instead of storing:

```
[
    {"id":28,"name":"Action"},
    {"id":12,"name":"Adventure"},
    {"id":10749,"name":"Romance"},
    {"id":37,"name":"Western"}
]
```

we would prefer:

```
["Action", "Adventure", "Romance", "Western"]
```

To accomplish this, define the following function.

```python
import ast

def convert(obj_list):
    required_list = []

    for dictionary in ast.literal_eval(obj_list):
        required_list.append(dictionary["name"])

    return required_list
```

Apply it to the `genres` column.

```python
df["genres"] = df["genres"].apply(lambda x: convert(x))
df["genres"][:5]
```

Each entry in the `crew` column contains metadata for every crew member involved in producing a movie.

Although this information is extensive, the **director** is generally the most influential crew member from the perspective of movie recommendations.

Therefore, we extract only the director's name.

```python
def getting_director(obj_list):
    required_list = []

    for dictionary in ast.literal_eval(obj_list):
        if dictionary["job"] == "Director":
            required_list.append(dictionary["name"])
            break

    return required_list
```

Apply the function:

```python
df["crew"] = df["crew"].apply(lambda x: getting_director(x))
```

## 2.6 Preprocessing the `cast` Feature

The `cast` column has the same structure as the `crew` column.

Rather than retaining every actor, we extract only the **top three billed cast members**, as these typically have the greatest impact on user preferences.

```
def three_top_cast(obj_list):
    required_list = []
    count = 0

    for dictionary in ast.literal_eval(obj_list):
        if count < 3:
            required_list.append(dictionary["name"])
            count += 1
        else:
            break

    return required_list
```

Apply the function to the `cast` column.

```
df["cast"] = df["cast"].apply(lambda x: three_top_cast(x))
df["cast"][:5]
```

```
0    [Sam Worthington, Zoe Saldana, Sigourney Weaver]
1       [Johnny Depp, Orlando Bloom, Keira Knightley]
2        [Daniel Craig, Christoph Waltz, Léa Seydoux]
3        [Christian Bale, Michael Caine, Gary Oldman]
4      [Taylor Kitsch, Lynn Collins, Samantha Morton]
```

Each movie is now represented by its **three leading actors**, which provides sufficient information while avoiding excessive feature dimensionality.
