

After transforming raw data into machine-understandable representations, the next step in a content-based recommender system is to determine which items are similar to one another so that relevant recommendations can be generated. Although this task may appear complex, its underlying principle is remarkably simple: recommendation is fundamentally a mathematical problem.

Content-based recommender systems compare either the intrinsic characteristics of items (such as movie genres, music styles, product attributes, or document features) or user preference profiles derived from previous interactions. The similarity between these representations is quantified using similarity and distance measures. Among the most widely used metrics are **Cosine Similarity**, **Euclidean Distance**, and **Jaccard Similarity**.

Each metric is appropriate for a particular type of data. We begin with one of the most widely used similarity measures in recommender systems.

---

# Cosine Similarity

Cosine Similarity measures the similarity between two feature vectors by computing the cosine of the angle between them. Unlike Euclidean distance, cosine similarity depends on the orientation of vectors rather than their magnitude. Consequently, two vectors pointing in nearly the same direction are considered highly similar even if their magnitudes differ considerably.

This property makes cosine similarity particularly suitable for high-dimensional sparse representations such as TF-IDF vectors, bag-of-words models, and other feature representations commonly used in recommender systems and information retrieval.

The cosine similarity between two vectors is defined as

$$  
Sim(A,B)=\frac{A\cdot B}{\lVert A\rVert\lVert B\rVert}  
$$

where

- $A$ is the feature vector of the first item.
    
- $B$ is the feature vector of the second item.
    
- $A\cdot B$ denotes the dot product of the two vectors.
    
- $\lVert A\rVert$ denotes the Euclidean norm of vector $A$.
    
- $\lVert B\rVert$ denotes the Euclidean norm of vector $B$.
    

For feature vectors containing non-negative values,

$$  
0\le Sim(A,B)\le1  
$$

A value close to **1** indicates highly similar items, whereas a value close to **0** indicates little or no similarity.

---

# Example

Consider the following movie dataset.

|Movie|Action|Comedy|Drama|
|---|:-:|:-:|:-:|
|Die Hard|1|0|0|
|The Mask|0|1|0|
|Titanic|0|0|1|
|Mr. & Mrs. Smith|1|1|0|

Assume a user likes **Die Hard** and **The Mask**.

Our objective is to determine which of the remaining movies is most similar to the user's interests.

## Step 1: Represent Movies as Feature Vectors

```text
Die Hard           → [1, 0, 0]
The Mask           → [0, 1, 0]
Mr. & Mrs. Smith   → [1, 1, 0]
Titanic            → [0, 0, 1]
```

## Step 2: Construct the User Profile

The user profile is obtained by combining the vectors of the movies the user likes.

$$  
User\ Profile=[1+0,0+1,0+0]=[1,1,0]  
$$

This profile indicates that the user prefers both the **Action** and **Comedy** genres.

## Step 3: Compute Cosine Similarity

### Similarity Between the User Profile and _Mr. & Mrs. Smith_

The cosine similarity is

$$  
Sim=\frac{[1,1,0]\cdot[1,1,0]}{\lVert[1,1,0]\rVert\lVert[1,1,0]\rVert}  
$$

The dot product is

$$  
[1,1,0]\cdot[1,1,0]=1\times1+1\times1+0\times0=2  
$$

The magnitude of each vector is

$$  
\lVert[1,1,0]\rVert=\sqrt{1^2+1^2+0^2}=\sqrt{2}  
$$

Substituting these values,

$$  
Sim=\frac{2}{\sqrt{2}\times\sqrt{2}}  
$$

Since

$$  
\sqrt{2}\times\sqrt{2}=2  
$$

we obtain

$$  
Sim=\frac{2}{2}=1  
$$

### Similarity Between the User Profile and _Titanic_

The cosine similarity is

$$  
Sim=\frac{[0,0,1]\cdot[1,1,0]}{\lVert[0,0,1]\rVert\lVert[1,1,0]\rVert}  
$$

The dot product is

$$  
[0,0,1]\cdot[1,1,0]=0\times1+0\times1+1\times0=0  
$$

The magnitude of the movie vector is

$$  
\lVert[0,0,1]\rVert=\sqrt{0^2+0^2+1^2}=1  
$$

The magnitude of the user profile is

$$  
\lVert[1,1,0]\rVert=\sqrt{2}  
$$

Therefore,

$$  
Sim=\frac{0}{1\times\sqrt{2}}=0  
$$

## Results

- **Mr. & Mrs. Smith** → Similarity = **1.0** → Best recommendation
    
- **Titanic** → Similarity = **0.0** → Not relevant to the user's interests
    

Therefore, **Mr. & Mrs. Smith** should be recommended to the user.

## Implementation Using Python and scikit-learn

```python
import pandas as pd
from sklearn.metrics.pairwise import cosine_similarity
from sklearn.feature_extraction.text import CountVectorizer

# Movie data
movies = pd.DataFrame({
    'title': ['Die Hard', 'The Mask', 'Titanic', 'Mr. & Mrs. Smith'],
    'genres': ['Action', 'Comedy', 'Drama', 'Action Comedy']
})

# Converting genres into numerical features
count_vectorizer = CountVectorizer()
genre_matrix = count_vectorizer.fit_transform(movies['genres'])

feature_names = count_vectorizer.get_feature_names_out()

genre_df = pd.DataFrame(
    genre_matrix.toarray(),
    columns=feature_names,
    index=movies['title']
)

print(genre_df)
print(genre_matrix)

# Calculating the cosine similarity matrix
cosine_sim = cosine_similarity(genre_matrix, genre_matrix)

# Building a user profile with the average vectors of favorite movies
favorite_movies = ['Die Hard', 'The Mask']
favorite_indices = movies[movies['title'].isin(favorite_movies)].index

user_profile = genre_matrix[favorite_indices].mean(axis=0)

# Calculating the similarity between the user profile and all movies
user_sim = cosine_similarity(user_profile, genre_matrix)

similarities = pd.DataFrame({
    'title': movies['title'],
    'similarity': user_sim.flatten()
})

recommendations = similarities[~movies['title'].isin(favorite_movies)]
recommendations = recommendations.sort_values(by='similarity', ascending=False)

print(recommendations)
```

This implementation provides a simple foundation for developing more sophisticated content-based recommender systems.

## Euclidean Distance

Euclidean Distance is one of the most common metrics for measuring the distance between two points in an $n$-dimensional space. In recommender systems, it is particularly suitable for comparing **numerical features**, where the similarity between two items is inversely proportional to the distance between their feature vectors. In other words, the smaller the Euclidean distance between two items, the more similar they are considered to be (2).

The Euclidean distance between two feature vectors is defined as

$$  
d(A,B)=\sqrt{\sum_{i=1}^{n}(A_i-B_i)^2}  
$$

where

- $A$ is the feature vector of the first item.
    
- $B$ is the feature vector of the second item.
    
- $A_i$ and $B_i$ denote the values of the $i$-th feature in vectors $A$ and $B$, respectively.
    
- $n$ is the total number of features (dimensions).
    

### Example

Consider the following dataset describing four products using two numerical features: **price** and **weight**.

|Product|Price|Weight|
|---|--:|--:|
|Product A|20|5|
|Product B|25|4|
|Product C|15|6|
|Product D|30|7|

Suppose a user has shown interest in **Product A**. Our objective is to compute the Euclidean distance between Product A and the remaining products in order to identify the most similar items.

### Step 1: Represent Products as Feature Vectors

Each product is represented by a feature vector containing its price and weight.

```text
Product A → [20, 5]
Product B → [25, 4]
Product C → [15, 6]
Product D → [30, 7]
```

### Step 2: Compute the Euclidean Distance

#### Distance Between Product A and Product B

The Euclidean distance is

$$  
d(A,B)=\sqrt{(20-25)^2+(5-4)^2}  
$$

Evaluating the squared differences gives

$$  
d(A,B)=\sqrt{(-5)^2+1^2}  
$$

$$  
d(A,B)=\sqrt{25+1}  
$$

$$  
d(A,B)=\sqrt{26}\approx5.10  
$$

#### Distance Between Product A and Product C

The Euclidean distance is

$$  
d(A,C)=\sqrt{(20-15)^2+(5-6)^2}  
$$

Evaluating the squared differences gives

$$  
d(A,C)=\sqrt{5^2+(-1)^2}  
$$

$$  
d(A,C)=\sqrt{25+1}  
$$

$$  
d(A,C)=\sqrt{26}\approx5.10  
$$

#### Distance Between Product A and Product D

The Euclidean distance is

$$  
d(A,D)=\sqrt{(20-30)^2+(5-7)^2}  
$$

Evaluating the squared differences gives

$$  
d(A,D)=\sqrt{(-10)^2+(-2)^2}  
$$

$$  
d(A,D)=\sqrt{100+4}  
$$

$$  
d(A,D)=\sqrt{104}\approx10.20  
$$

### Results

The computed distances indicate that

- **Product A** and **Product B** → Distance = **5.10** → Higher similarity
    
- **Product A** and **Product C** → Distance = **5.10** → Higher similarity
    
- **Product A** and **Product D** → Distance = **10.20** → Lower similarity
    

Therefore, **Product B** and **Product C** are the closest products to **Product A** in terms of price and weight and would be considered the most suitable recommendations.

## Implementation Using Python

```python
import numpy as np

# Defining features for products
products = {
    'Product A': [20, 5],
    'Product B': [25, 4],
    'Product C': [15, 6],
    'Product D': [30, 7]
}

# Euclidean distance calculation function
def euclidean_distance(A, B):
    return np.sqrt(np.sum((np.array(A) - np.array(B)) ** 2))

# Calculating the distance between products
for product_a, features_a in products.items():
    for product_b, features_b in products.items():
        if product_a != product_b:
            distance = euclidean_distance(features_a, features_b)
            print(f"Distance between {product_a} and {product_b}: {distance:.2f}")
```

This implementation demonstrates the basic computation of Euclidean distance and can serve as a foundation for distance-based similarity calculations in recommender systems.

## Jaccard Similarity

The similarity measures introduced so far are primarily designed for continuous numerical feature vectors. However, many recommendation problems involve **binary data**, where each feature simply indicates the **presence** or **absence** of a characteristic. In such cases, metrics designed specifically for set comparison are more appropriate. One of the most widely used measures for this purpose is the **Jaccard Similarity Coefficient**.

Jaccard Similarity measures the proportion of shared features relative to the total number of unique features present in either item. Consequently, two items with many common features will have a Jaccard similarity close to **1**, whereas items sharing few or no features will have a similarity close to **0** (3).

The Jaccard similarity between two sets is defined as

$$  
J(A,B)=\frac{|A\cap B|}{|A\cup B|}  
$$

where

- $A$ is the set of features associated with the first item.
    
- $B$ is the set of features associated with the second item.
    
- $A\cap B$ denotes the intersection of the two sets (shared features).
    
- $A\cup B$ denotes the union of the two sets (all unique features).
    

### Example

Suppose four items are represented using binary features, where a value of **1** indicates the presence of a feature and **0** indicates its absence.

|Item|Feature 1|Feature 2|Feature 3|Feature 4|
|---|:-:|:-:|:-:|:-:|
|Item A|1|0|1|1|
|Item B|0|1|1|0|
|Item C|1|1|0|0|
|Item D|0|0|1|1|

For example, **Item A** contains Features 1, 3, and 4.

### Step 1: Compute the Jaccard Similarity

#### Jaccard Similarity Between Item A and Item B

The common features are

$$  
A\cap B={3}  
$$

Therefore,

$$  
|A\cap B|=1  
$$

The union of their features is

$$  
A\cup B={1,2,3,4}  
$$

Hence,

$$  
|A\cup B|=4  
$$

The Jaccard similarity is

$$  
J(A,B)=\frac{1}{4}=0.25  
$$

---

#### Jaccard Similarity Between Item A and Item C

The intersection is

$$  
A\cap C={1}  
$$

Therefore,

$$  
|A\cap C|=1  
$$

The union is

$$  
A\cup C={1,2,3,4}  
$$

Thus,

$$  
|A\cup C|=4  
$$

The Jaccard similarity becomes

$$  
J(A,C)=\frac{1}{4}=0.25  
$$

---

#### Jaccard Similarity Between Item A and Item D

The intersection is

$$  
A\cap D={3,4}  
$$

Therefore,

$$  
|A\cap D|=2  
$$

The union is

$$  
A\cup D={1,3,4}  
$$

Hence,

$$  
|A\cup D|=3  
$$

The Jaccard similarity is

$$  
J(A,D)=\frac{2}{3}\approx0.67  
$$

### Results

The computed similarities are

- **Item A** and **Item B** → Jaccard Similarity = **0.25** → Low similarity
    
- **Item A** and **Item C** → Jaccard Similarity = **0.25** → Low similarity
    
- **Item A** and **Item D** → Jaccard Similarity = **0.67** → Highest similarity
    

Therefore, **Item D** is the most similar item to **Item A** according to the Jaccard Similarity Coefficient.

## Implementation Using Python

```python
import numpy as np

# Defining binary attributes for items
items = {
    'Item A': [1, 0, 1, 1],
    'Item B': [0, 1, 1, 0],
    'Item C': [1, 1, 0, 0],
    'Item D': [0, 0, 1, 1]
}

# Jaccard similarity calculation function
def jaccard_similarity(A, B):
    intersection = np.sum(np.array(A) & np.array(B))  # Feature intersection
    union = np.sum(np.array(A) | np.array(B))         # Feature union
    return intersection / union

# Calculating the Jaccard similarity between items
for item_a, features_a in items.items():
    for item_b, features_b in items.items():
        if item_a != item_b:
            similarity = jaccard_similarity(features_a, features_b)
            print(f"Jaccard similarity between {item_a} and {item_b}: {similarity:.2f}")
```

This implementation demonstrates how the Jaccard Similarity Coefficient can be used to compare binary feature vectors and serves as a foundation for recommendation systems and other applications involving set-based similarity measures.
